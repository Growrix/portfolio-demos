// GUARDRAILS

Safe by design

AI extracts, rules decide

Approval is decided by code from the numbers — never by the model.

Duplicate protection

File fingerprint + vendor/number/total match. No double payments.

Privacy

W-9 tax IDs stored as last 4 digits only; files are not kept in the database.

Injection-proof

Document text is treated as data; instructions inside a file are flagged.

Cost control

Wrong types and oversize files rejected before any AI call; vision only for scans/photos.

One-time links

Approve/Reject links carry a random token and expire after one use; link-preview bots are blocked.
