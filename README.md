# portfolio-demos

Static HTML automation demos for Upwork / portfolio, hosted on one Vercel project.

## Live

- Root (Lead Pipeline, Upwork link): https://lead-pipeline-demo.vercel.app/
- Demo index: https://lead-pipeline-demo.vercel.app/demos
- Support Email Classifier: https://lead-pipeline-demo.vercel.app/support-email-classifier

## Add a new demo

1. Create `/<slug>/index.html` (self-contained HTML is fine).
2. Add a card/link for it in `/demos/index.html`.
3. Commit and push to `main` — Vercel auto-deploys.

Do not put secrets, API keys, or private credentials in this repo.
